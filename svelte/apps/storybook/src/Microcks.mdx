# Microcks components

The **microcks** tier holds the domain components: they draw Microcks concepts such as an API and its version, an operation and its mock URL,
a conformance score, a test run and its steps. They are native Svelte code over the same layered stylesheet as the natural tier,
and most of them reuse natural components inside (`OperationRow` uses `MethodTag` and `MockUrl`).

## When to use it

- When the UI shows a Microcks object: use `ApiBadge` for an API, `StatusBadge` for a test outcome, `OperationRow` for an operation.
  They keep the same words, icons and colors on every screen.
- In plugins, to look native next to the core screens: every item also has an HTML recipe.
- Not for generic chrome: a plain button, form or table belongs to the **Natural** tier.

## Items

The list is generated at build time from the registry (`packages/registry/items/*.json`, `"tier": "microcks"`). Each name links to its Docs page.
