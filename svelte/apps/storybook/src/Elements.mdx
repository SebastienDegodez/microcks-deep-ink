# Elements

The **element** tier holds the only two Web Components, kept where the logic is heavy:

- `<workflow-loom>` draws an Arazzo workflow: lanes per source, steps, data threads, `retry` and `end` actions, and a built-in table view.
- `<plugin-slot>` is the plugin host: it renders the contributions of installed plugins for an extension point, in light DOM.

Each ships as a self-contained bundle inside the package, with a thin Svelte wrapper, `WorkflowLoom` and `PluginSlot`.
Importing the wrapper registers the element: there is nothing else to load.
The wrappers set the properties (`steps`, `context`) and turn the element events into callbacks (`onstepselect`, `onlensselect`).

## When to use it

- `WorkflowLoom` to show an Arazzo workflow, at design time or for a run. Pass `tableToggle={false}` when the page already has its own Steps table.
- `PluginSlot` at each extension point of the shell (`nav.items`, `service.tabs`, `cockpit.widgets`...). Its children are the fallback when no plugin contributes.
- In Svelte, always use the wrappers rather than the bare tags. In plain HTML or Angular, copy the bundle with the item.
