# Natural components

The **natural** tier holds the generic UI primitives: buttons, form controls, tables, dialogs, tabs, menus, panels, plus the tokens, the base styles and the icons.
Each one is a native HTML element (`<button>`, `<input>`, `<table>`, `<dialog>`) styled by a plain class (`.button`, `.input`, `.table`).
The React components only add the wiring: labels and `aria-describedby` in `Field`, roving focus in `Tabs` and `Menu`, focus return in `Dialog`.
None of them knows about Microcks.

## When to use it

- For any screen chrome, form, list or dialog, in the Microcks UI or in a plugin.
- When a component does not exist yet: compose natural components before writing new CSS.
- In plain HTML or Angular, the same class names apply: copy the recipe from the **Copy** panel of each story.

Reach for the **Microcks** tier when the UI shows a Microcks concept (an API, an operation, a test run).
