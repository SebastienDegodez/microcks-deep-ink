Microcks Deep Ink

A design system proposal for the Microcks UI v2: native HTML styled by a CSS class API, React and Angular code you copy into your app, and two Web Components (Arazzo Loom, plugin slot).

This is a demo, not an official Microcks release. Nothing is published on npm; components and APIs may change or disappear without notice. Accessibility status: not audited (RGAA 4.1.2 target).
